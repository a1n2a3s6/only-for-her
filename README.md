# 💗 Only For Her — عالم معمول عشانكِ ♡

An interactive, cinematic romantic storybook website crafted as a digital gift — built in a single self-contained HTML file with handcrafted SVG illustrations, smooth animations, optional Web Audio music box, and full Arabic RTL + mobile-first support.

🔗 **[Live Demo]([https://USERNAME.github.io/only-for-her/](https://ziona-eta.vercel.app))**

[preview/demo.gif]

## ✨ Highlights
- **9 Story-Driven Scenes:** Opening bouquet reveal, sunlit welcome garden, interactive rose garden (8 roses + hidden golden rose), 3D wax-sealed love letter, interactive teddy bear nook, velvet night sky with a connectable heart constellation, Polaroid memory album, jar of 32 love notes, and a midnight grand finale.
- **100% Original SVG Artwork:** Custom animated teddy bear with multiple moods (idle, blink, shy, hug, dance, celebrate) and layered roses — no external image dependencies.
- **One-Place Personalization:** Edit her name, your signature, messages, memories, and notes inside the `loveStory` config object in `index.html`.
- **Works Everywhere:** Mobile-first, keyboard-accessible, `prefers-reduced-motion` aware, and saves progress locally.

## 🚀 Customize & Deploy in 2 Minutes
1. **Fork** this repository.
2. Open `index.html` and edit the `loveStory` object (`herName`, `herNameEn`, `myName`, `roses`, `loveNotes`, `memories`).
3. Enable **GitHub Pages** (`Settings → Pages → main / root`) and share your link!
